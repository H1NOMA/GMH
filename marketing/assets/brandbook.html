01 · Идея знака

Знак — «сеть мира»: тонкий шестиугольник (стол, кость, рамка правил) и созвездие связанных узлов внутри — граф связей, сердце приложения. Один узел акцентный: ваша текущая история. Никаких градиентов на самом знаке, никакого золота с бликами — только линия, точка и одна тёплая амбра.

Использование

  • Знак живёт отдельно (иконки) и в паре со шрифтовым логотипом (капсулы).
  • Охранное поле вокруг знака — не меньше толщины его стороны.
  • На тёмном — пергаментная линия; инверсию на светлом делать чернильной (#100E0A).

Нельзя

  • Не наклонять, не добавлять тени, свечение и золотые градиенты.
  • Не менять цвет акцентного узла на несистемные цвета.
  • Не ставить знак на пёстрые скриншоты без затемняющей подложки.

02 · Палитра

Ink#100E0A · фон
Surface#191610 · панели
Parchment#E9DFCB · текст, линии знака
Dim#968A74 · вторичный текст
Accent#C08A3E · единственный акцент
Приглушённая амбра #C08A3E — не «золото»: без бликов, без градиентов, всегда матовая. В маркетинге используется дозированно: акцентный узел, тонкая линейка, редкие выделения. Неоновые цвета киберпанк-темы — внутриигровая палитра, в идентику магазина их не тянем.

## Your entire world in one place — and it stays yours
Game Master's Hub is a local-first workspace for tabletop game masters:
every character, location, item, faction, quest and session note lives on
your device, connected into one navigable web. No account, no subscription,
no cloud — back up and move worlds as a single archive file.

## Write lore that links itself
- Rich-text editor with images, file attachments and version history
- Type @ to mention any entry — links are two-way and feed the graph
- Full character profiles: stats grid, biography, relationships, inventory
- D&D-style stat cards: spells, monster stat blocks, magic items
- Interactive relationship graph of your whole world

## Run the table, not the paperwork
- Campaign dashboards with quest boards and session logs
- Instant full-text search across everything
- Tags, favorites, filters and a tag manager
- Printable PDF world book and JSON export

## Make it your system
- Custom sections with their own fields via the Section Constructor
- Two world styles: classic Fantasy or neon Cyberpunk — per world
- English, Russian, German, French and Chinese interface
