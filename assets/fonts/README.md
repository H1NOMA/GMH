# Bundled fonts

Roboto (Regular, Italic, Medium, Bold) — copyright Google, licensed under
the Apache License, Version 2.0: <https://www.apache.org/licenses/LICENSE-2.0>.
Sourced from the Flutter SDK's material fonts bundle.

Bundling gives the desktop builds a consistent Material typeface and lets
`flutter test` render real text for the User Guide screenshot generator
(`test/help_screenshots_test.dart`).

Noto Sans SC (Regular), subset to the GB2312 character set plus CJK and
full-width punctuation — copyright Google/Adobe, licensed under the SIL
Open Font License 1.1 (see `OFL-NotoSansSC.txt`). Used only to embed
Chinese text in the PDF world book export.
