# Публикация Game Master's Hub на itch.io

Пошаговый план: страница, загрузка сборок, тексты и схема монетизации
«бесплатно + добровольная поддержка». Все ассеты и тексты — в
`marketing/assets/` (брендбук: `marketing/assets/brandbook.html`),
скриншоты — в `marketing/screenshots/`.

---

## 1. Аккаунт и страница проекта

1. Регистрация на [itch.io](https://itch.io) — обычный аккаунт, затем в
   настройках включить **Developer mode** (появится Dashboard).
2. Dashboard → **Create new project**:
   - **Title:** Game Master's Hub — Worldbuilding & Campaign Manager
   - **Project URL:** `gmh` → страница будет `username.itch.io/gmh`
   - **Classification:** Tools
   - **Kind of project:** Downloadable
   - **Release status:** Released
   - **Pricing:** **No payments** (важно — см. раздел «Монетизация»)
3. Оформление: Cover image `cover_630x500.png`, баннер `banner_960x400.png`,
   все 10 скриншотов из `marketing/screenshots/` (порядок — в брендбуке,
   раздел 04), тексты описания — брендбук, раздел 06 (уже в Markdown,
   вставляются как есть; на страницу идёт английский, остальные языки —
   в конец описания ссылкой «Interface languages: EN/RU/DE/FR/ZH»).
4. Теги (до 10): `worldbuilding, tabletop, dungeons-and-dragons, ttrpg,
   game-master, campaign, rpg, fantasy, cyberpunk, note-taking`.

## 2. Загрузка сборок

Два пути — руками или через CI (рекомендуется CI):

**Руками:** страница проекта → Edit → Uploads → загрузить
`gmh-X.Y.Z-setup-windows-x64.exe` и `gmh-X.Y.Z-windows-x64-portable.zip`
из GitHub-релиза, у обоих отметить платформу Windows.

**Через CI (butler):** в репозитории уже есть
`.github/workflows/itch-release.yml`:
1. itch.io → Settings → **API keys** → сгенерировать ключ.
2. GitHub-репозиторий → Settings → Secrets → добавить `BUTLER_API_KEY`.
3. Проверить `ITCH_TARGET` в workflow (`username/gmh`).
4. Запустить workflow (или пушнуть тег `v*`) — butler зальёт билд каналом
   `windows` с версией из pubspec. itch.io сам ведёт историю версий и
   докачивает пользователям только дельту через [приложение itch](https://itch.io/app).

## 3. Монетизация: бесплатно + добровольная поддержка

Важная вводная: **выплаты itch.io идут только через PayPal или Stripe** —
для получателя из РФ оба недоступны. Поэтому опция «Donate / Pay what you
want» внутри itch.io деньги фактически не доведёт. Рабочая схема:

1. **Pricing = No payments.** Приложение полностью бесплатно, никакой
   витринной цены — это честно и снимает все вопросы с налоговым
   интервью itch.io (W-8BEN нужен только при включённых платежах).
2. **Донаты — внешними ссылками** на сервисы, которые работают с РФ:
   - [Boosty](https://boosty.to) — разовые донаты + подписки уровней,
     вывод на карты РФ; де-факто стандарт у русскоязычных инди.
   - [DonationAlerts](https://www.donationalerts.com) — разовые донаты.
   - ЮMoney (кошелёк-копилка) — простые переводы без подписок.
   Ссылку разместить: в конце описания страницы itch.io («Support the
   project»), в README репозитория и в разделе Help внутри приложения.
3. **Уровни поддержки на Boosty** (пример):
   - 200 ₽/мес — «Хранитель мира»: имя в разделе благодарностей релиза;
   - 500 ₽/мес — «Соавтор»: голосование за следующие фичи, ранние сборки;
   - разовый донат — просто «спасибо».
4. **Что не делать:** не прятать функции за донат (испортит рейтинг и
   отзывы бесплатного инструмента), не включать itch-платежи «на будущее»
   — пока их некуда выводить, это только создаст налоговую отчётность.

**Почему free правильно и стратегически:** бесплатный инструмент на
itch.io собирает коллекции/рейтинги/рекомендации быстрее платного,
а конверсия в донаты у нишевых DM-инструментов сопоставима с выручкой от
цены $5–10 при том, что аудитория растёт кратно быстрее. Если позже
появится юрлицо/счёт за рубежом — цену или «suggested donation» можно
включить одним переключателем, ничего не переделывая.

## 4. После публикации

- **Devlog:** каждую заметную версию сопровождать постом (itch.io
  показывает devlog-посты подписчикам и в ленте) — тексты можно собирать
  из чейнджлога релизов GitHub.
- **Сообщества:** r/DMToolkit, r/worldbuilding, форумы itch.io
  (Release Announcements), тематические Discord-серверы DM-инструментов.
- **Метрики:** itch.io Dashboard → Analytics (просмотры, загрузки,
  переходы) — смотреть, какие скриншоты/теги приводят трафик.
- **Обновления:** пуш тега `v*` собирает GitHub-релиз и заливает сборку
  на itch.io одним действием.
